Overview

The mesh can be right in one view and wrong in the next

Hybrid Mesh–Gaussian rendering combines compact textured surfaces with flexible 3D Gaussian primitives. Existing hybrids follow an additive formulation, where Gaussian residuals compensate for errors left by the mesh. But not every Mesh–Gaussian conflict is caused by missing content: residual geometry errors, occlusion mismatch, texture-projection artifacts, and view-dependent appearance can make the same mesh content consistent in one view but inconsistent in another.

We therefore formulate hybrid rendering as a multi-view inconsistency problem and present Gaussolve, a subtract-and-refill framework. A lightweight Neural Dissolve Field, parameterized by scalar spherical-harmonic Gaussians, learns where and from which viewing directions mesh content should be dissolved. Continuous transmittance fusion progressively exposes the residual Gaussians behind it, preserving their gradients and avoiding hard visibility switches. The result is higher visual fidelity with fewer Gaussians and faster rendering.

Method

Subtract what conflicts, refill what is revealed

Projection-textured mesh

Training images are projected straight onto an independently reconstructed mesh, keeping the observed high-frequency appearance.

Neural Dissolve Field

Scalar-SH Gaussians predict how much of the mesh to dissolve, and from which viewing directions.

Continuous transmittance fusion

Dissolving the mesh smoothly exposes the residual Gaussians behind it, so they keep learning instead of being cut off.

Hard visibility vs. continuous fusion

With the same textured mesh, a Hard-Z hybrid treats the mesh as an opaque occluder. Gaussolve dissolves what is inconsistent and lets the Gaussians fix it.

Dissolve that depends on the viewing direction

With scalar SH, the field dissolves the mesh only from the directions where it conflicts, so the Gaussians can recover highlights and reflections.
